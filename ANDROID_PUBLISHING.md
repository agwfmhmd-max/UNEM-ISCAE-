# UNEM ISCAE Android / Google Play

The `android-app/` directory is the Android publishing project for the live UNEM ISCAE platform.

The Android wrapper targets API 36, matching Google Play's new-app requirement effective 31 August 2026.

Open `android-app/` in Android Studio, install SDK 36 + Build Tools 36.0.0, sync, then create a signed AAB from **Build > Generate Signed App Bundle / APK > Android App Bundle**.

UNEM ISCAE — Internal Browser / Web Proxy

تم دمج طبقة Proxy داخل الخادم لمعالجة مشكلة المواقع الخارجية التي لا تعمل بشكل صحيح داخل iframe.

الوظيفة:
- openWebViewer(url, title) يمرر الموقع إلى /api/web-proxy بدلاً من تحميله مباشرة داخل iframe.
- روابط HTML وCSS والصور والسكريبتات وforms يعاد توجيهها عبر الـ Proxy.
- fetch و XMLHttpRequest و window.open والتنقل في النماذج داخل الصفحة المعروضة يتم اعتراضها وتوجيهها إلى الـ Proxy.
- Redirects تبقى داخل المتصفح الداخلي.
- لا يوجد تحويل تلقائي إلى متصفح خارجي.
- يدعم GET/POST/PUT/PATCH/DELETE/OPTIONS/HEAD.
- يتم تمرير Cookies الخاصة بكل نطاق عبر أسماء معزولة لتقليل تداخل جلسات المواقع.

ملاحظة مهمة:
هذا الحل يعمل مع المواقع العامة HTTP/HTTPS التي تسمح بتشغيل وظائفها بعد إعادة تمريرها. بعض المواقع التي تعتمد على WebSocket، تطبيقات محمية بتوقيع Origin صارم، أو آليات anti-bot/DRM قد تحتاج تكاملًا خاصًا ولا يمكن ضمان تشغيلها بالكامل بواسطة Proxy عام.

الأمان:
الـ Proxy يرفض localhost والعناوين الخاصة الشائعة لمنع استخدامه للوصول إلى خدمات الشبكة الداخلية. لا تستخدمه للوصول إلى خدمات إدارية داخلية.
